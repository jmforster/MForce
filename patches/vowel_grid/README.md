# vowel_grid — Speech + Sing formant vowel patches

56 instrument-style patches, generated by `tools/gen_vowel_grid.py --f1-retune`
(the flag adds the F1-retune curve to the 11 physics-limited entries — see
below; without it the grid regenerates in its original 2026-08-02 form),
verified by `tools/verify_vowel_grid.py` (renders in `renders/vowel_grid/`).
Data catalog: `docs/research/formants/CATALOG.md` (authoritative provenance).

Architecture = the validated liar2 recipe (`tools/gen_liar2.py`), static:
flat `FullPartials` buzz (160 partials, rolloff 0) -> one `FormantSpectrum`
of five `Formant` nodes (power 2.0) -> `AdditiveSource` with
`formantWeight 1.0`, `formantFloor 0.0` (out-of-band silent). Instrument
block maps `frequency`; the score plays the nearest MIDI note to the group
F0 for 3 s, so rendered f0 is the equal-tempered note frequency.

## Vowel naming (ASCII file name -> IPA)

Speech uses the Hillenbrand codes: `AE`=æ (had), `AH`=ɑ (hod), `AW`=ɔ
(hawed), `EH`=ɛ (head), `EI`=e(ɪ) (hayed, diphthongal), `ER`=ɝ (heard,
rhotic — low F3), `IH`=ɪ (hid), `IY`=i (heed), `OA`=o(ʊ) (hoed,
diphthongal), `OO`=ʊ (hood), `UH`=ʌ (hud), `UW`=u (who'd).
Sing uses the Csound labels `A E I O U` = the Italian five-vowel singing set
[ɑ~a, e, i, o, u] (close-mid e/o — CATALOG.md §1 inference).

## Derived quantities (speech only; Sing is used verbatim)

- **F1–F3**: Hillenbrand steady-state means, unmodified.
- **F4**: Hillenbrand mean where `n_f4_measured >= n/2` — true for every
  cell in this grid, so all F4s are measured.
- **F5**: Klatt (1980) male default 3750 Hz x R_g, where
  R_g = mean_F3(group)/mean_F3(men) with `er` excluded (rhotic outlier):
  R = 1.000 (M), 1.138 (W), 1.240 (C) -> F5 = 3750 / 4267 / 4649 Hz.
- **Amplitudes** (Hillenbrand publishes none): gain_i = F1/F_i, gain(F1)=1
  — amplitude ~ 1/f, i.e. a -6 dB/octave source-spectrum falloff. This
  reproduces the validated liar2 gain family (e.g. IY F2 gain 0.148 vs
  liar2 EE 0.18).
- **Bandwidths** (Hillenbrand publishes none): Klatt (1980) Table I typical
  B1..B5 = 50/70/110/250/200 Hz (Hawks–Miller coefficients not yet
  obtained — see CATALOG.md §7).

**Engine width = 8 x literature bandwidth** (WIDTH_MULT 8, Matt's current
default from the liar2 ladder; engine width is the full band footprint,
center +/- width/2, not the -3dB bandwidth). The Csound table's bw column is
the same -3dB-style 40–200 Hz family as Klatt's B1–B3, so the same x8 is
applied to the Sing set: engine widths land at 320–1600 Hz, the same range
as the speech widths (400–2000 Hz). Sing dB amps convert linear as
10^(dB/20).

## Verification (2026-08-02)

`tools/verify_vowel_grid.py`: **56/56 PASS**.

- Envelope match: measured harmonic amplitudes (windowed DFT, steady middle
  2 s) vs the patch's exactly predictable envelope (max-over-formants
  power-2 taper on each harmonic) — correlation 1.000 on all 56 renders.
- Peak check: F1/F2/F3 each produce a measured peak on the predicted
  harmonic wherever the prediction has a distinct peak; offsets are within
  harmonic quantization (<= 0.75 f0).
- All renders non-silent (rms 0.007–0.046).

### Physics-limited entries (11) — F1-retune curve applied (2026-08-05)

All 11 entries below now carry a second `paramMap.frequency` target on the
`f1` Formant node: `{"target": "f1.frequency", "curve": [[hz, F1eff], ...]}`
implementing **effective F1 = clamp(f0, table F1, 1100)** — flat at the table
F1 below it, identity (F1 tracks the sung note) above, capped at 1100 Hz.
Knots are semitone-spaced because the engine curve (instrument.h
`ParamSlot::map`) interpolates linear-value in log-frequency; dense knots keep
`curve(f0)` within 0.05 % of f0. F2–F5 are untouched. This is what real
sopranos do (F1 retuning to the fundamental).

At the grid's scored notes the curve changes only the three true
soprano-problem renders — the other eight keep table F1 (f0 < F1 there; the
curve exists so those patches stay correct at higher notes):

| patch | table F1 | f0 | eff. F1 | h1 change |
|---|---|---|---|---|
| `Sing_Soprano_E` | 350 | 440 | 440 | **+8.2 dB** |
| `Sing_Soprano_I` | 270 | 440 | 440 | **+21.4 dB** |
| `Sing_Soprano_U` | 325 | 440 | 440 | **+14.9 dB** |

All three now peak at the fundamental with full F1 gain (h1 −29.3 dBFS in
each, vs −37.5/−50.7/−44.2 before); the verifier's "unexcitable / soprano
problem" class is empty (`F1 ok (+0)` on all three). `_manifest.json` records
the effective F1 at the rendered note (`freq`) plus the table value
(`table_freq`) and `"f1_retune": true`.

**Perceptual tradeoff:** the power at the fundamental returns, but vowel
identity blurs — with F1 sitting on h1, E/I/U differ mainly in F2+, which is
exactly the physiologically accurate situation (sopranos' vowels are genuinely
hard to distinguish at high f0).

**Soprano problem (original 2026-08-02 finding, now mitigated):** F1 below f0
is unexcitable — no harmonic falls inside the first formant band, so the
spectrum peaked at an attenuated fundamental: `Sing_Soprano_E` (F1 350 < 440),
`Sing_Soprano_I` (270 < 440), `Sing_Soprano_U` (325 < 440).
`Sing_Soprano_O` (F1 450) and `Sing_Soprano_A` escape only marginally.

**Merged formants (skirt overlap at x8 widths and/or spacing < harmonic
resolution — the formant becomes a shoulder, not a separate peak):**

| patch | merged |
|---|---|
| `Speech_W_AW` | F2 1188 absorbed into F1 804 skirt |
| `Sing_Bass_U` | F2 600 into F1 350 skirt (F2 amp -20 dB) |
| `Sing_Tenor_O` / `Sing_Tenor_U` | F3 merges with F4 (2600/2800, 2700/2900) |
| `Sing_Alto_A` / `Sing_Alto_U` | F2 into F1 skirt |
| `Sing_Soprano_A` | F1+F2 (800/1150) share harmonic 2 (880) |
| `Sing_Soprano_E` / `Sing_Soprano_O` | F2 no distinct peak at f0 440 |

These are exactly the entries to expect trouble from in audition; the
verifier confirms the engine rendered what the patch specified (corr 1.000)
— the limit is the data + f0, not a bug. The F1-retune curve does not address
merging (it moves only F1); after the retune the verifier reports 10
physics-limited entries, all of the merged class (`Sing_Soprano_I` dropped
off the list entirely, and `Sing_Soprano_U` gained an F1/F2 shared peak at
440 since F1 now sits on h1). 56/56 still PASS, corr 1.000.
