# UI Groups Implementation Plan (spec chunk 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Groups per spec §3 — flat-graph UI structure with auto-derived
interfaces, breadcrumb drill-in, and the in-context Listen tap (toggle +
"Listen here" on any node).

**Architecture:** Engine stays blind: the patch JSON keeps every node
top-level; a root-level `groups` section records membership
(`[{name, members:[ids], pos:[x,y]}]`, members may name other groups).
The editor filters what it draws by the current drill-in path; collapsed
groups render as synthetic imnodes nodes whose pins PROJECT the real
boundary links (interacting with a projected pin edits the underlying real
link). Listening is a tap: one global tap target consulted by
`find_output_source()` (in-UI renders) and by a `graph.output` override in
the playback temp save only — a user-facing Save never persists the tap.

**Tech Stack:** tools/mforce_ui/main.cpp (ImGui/imnodes), nlohmann::json.
No engine edits. Gate: tools/test_stable_roundtrip.py stays green; groups
present-vs-stripped must render byte-identical (engine blindness proven).

### Task 1: Data model, persistence, rename integration
- `struct NodeGroup { std::string name; std::vector<std::string> members;
  ImVec2 pos{0,0}; int editorId{-1}; std::vector<int> pinIds; }` +
  `static std::vector<NodeGroup> s_groups;` editorId/pinIds are synthetic
  imnodes ids allocated from the same s_nextId pool at load/create.
- Helpers: `group_of(label) -> NodeGroup*` (innermost group whose members
  contain the label — node label or group name), `group_by_name`,
  `visible_at_path(label)` (member chain vs s_groupPath),
  `group_output_node(NodeGroup&) -> GraphNode*` (single outbound source,
  else last topo member with outputs).
- Load: parse root `groups` after nodes; drop entries whose members
  vanished (warn). Save (patch + node paths): emit `groups` verbatim from
  the model. new_graph/load reset s_groups + s_groupPath.
- rename_node: rewrite membership entries; renaming a NODE checks
  uniqueness against group names too (and group rename vice versa).
- Gate check: --roundtrip carries groups; CLI ignores them (render
  byte-identical with the section stripped — add this A/B to the task-5
  verification).

### Task 2: View filtering, collapsed groups, drill-in, breadcrumb
- `static std::vector<std::string> s_groupPath;`
- Editor loop: draw only nodes with `visible_at_path(node.label)`; draw a
  collapsed synthetic node (`ImNodes::BeginNode(g.editorId)`) for each
  group whose PARENT level is the current path: title = name, one input
  pin per boundary-inbound target pin (label = "node.pin"), one output
  pin. Boundary computation each frame from s_links (cheap at this graph
  size).
- Link projection: a link with exactly one visible endpoint renders as a
  synthetic ImNodes::Link to the group pin that represents its hidden
  side (synthetic link id = real link id + offset flag so destroy events
  map back). Both-hidden links aren't drawn.
- IsLinkCreated on a synthetic pin: translate to the represented real pin
  and run the existing create logic. IsLinkDestroyed on a projected link:
  delete the real link.
- Double-click on a collapsed group (IsNodeHovered + IsMouseDoubleClicked)
  pushes s_groupPath; breadcrumb bar above BeginNodeEditor: `PatchName ▸
  A ▸ B`, each ancestor clickable (truncate path), right-aligned Listen
  toggle (task 4). Node creation while inside a group auto-adds the new
  node to that group's members.
- Group node position: persist g.pos from GetNodeGridSpacePos each frame
  it is visible (SetNodeGridSpacePos on first draw after load).

### Task 3: Group / Ungroup operations
- Context menu (selection ≥1, no Output node selected): **Group
  selection** — validate two-output rule (refuse via transport_set_status
  naming offenders), create NodeGroup{unique name "Group"/"GroupN",
  members = selected labels + any selected group names at this level},
  collapsed pos = selection centroid. Members keep canvas positions.
- **Ungroup** on a collapsed group node: splice members into the parent
  level (membership list of parent group gains them, or top level),
  delete the record. Fully reversible with Group.
- Properties panel: selecting a collapsed group shows its name in the
  rename field (shared validation; renames update child membership
  references).

### Task 4: Listen tap
- State: `static int s_listenTapNode = -1;` (graph node id; -1 = patch
  output) + `static std::unordered_map<std::string,bool> s_groupListen;`
  (per-group session memory, default true = listen to group on drill-in).
- Breadcrumb toggle (innermost group): `Patch | Group`, active side
  ImVec4(0.5,0.8,0.5,1); flips s_groupListen[name] and sets/clears the
  tap to group_output_node. Drill-in applies the remembered choice;
  navigating to top level clears group-derived taps (manual taps stay).
- Node context menu: **Listen here** / **Stop listening here** (sets/
  clears s_listenTapNode). draw_node renders a speaker glyph ("<)))" text
  in green) in the title row of the tapped node; collapsed groups show it
  when their output is the tap.
- Plumbing: find_output_source() returns the tap node's dspSource when
  set (fallback: patch output). save_patch_graph gains
  `bool tapOverride=false` — only get_playback_patch_path passes true,
  emitting the tap node as graph.output in the TEMP file; user-facing
  saves never persist taps. Spectrum/Waveforms/keyboard follow for free
  (all route through find_output_source or the temp file).
