# Comp Walk Round 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Derived motifs (2 atoms + declared transforms) and harmonic anchor selection (Matt's 3 rules + stacked chord-tone weights) generate a 10-seed sibling batch over the Mary harmony — every render a legal nursery tune.

**Architecture:** `realize_motifs` learns to synthesize content-less `derivedFrom` motifs through `figure_transforms::apply` (new `Complexify` op, param = target note count). A new `anchor_selector.h` enumerates legal (start-degree, leadStep-chain) tuples per phrase against the section's harmonyTimeline, hard-filters R1–R3, scores chord-tone notes with the bar-final/figure-final/long boosts, seeded-roulettes among legal chains, and writes startingPitch + dense connectors into the working PhraseTemplate inside `DefaultPassageStrategy::compose_passage`. All opt-in via `PassageTemplate.anchorMode = "harmonic"`.

**Tech Stack:** header-only C++17 music model, engine_tests CHECK harness, CMake Release, python null-test script.

**Spec:** `docs/superpowers/specs/2026-09-21-comp-walk1-design.md` — binding, including §7 known limitations.

### Task 1: TransformOp::Complexify
- Files: figure_transforms.h (enum + `apply` case), templates_json.h (to/from_json names `"complexify"`), tools/engine_tests/main.cpp.
- apply case: `case TransformOp::Complexify: { int target = param > 0 ? param : base.note_count() + 1; float amount = std::max(0.0f, float(target)/std::max(1, base.note_count()) - 1.0f); return complexify(base, rng, amount); }`
- Tests: rep3 (3 units) + param 4 → 4 units, total duration 4.0 preserved, seeded determinism (same seed twice ⇒ equal units); JSON roundtrip of the op name.
- Steps: failing test → implement → pass → commit.

### Task 2: Derived-motif synthesis in realize_motifs
- Files: composer.h (`realize_motifs`), templates_json.h only if gaps found, engine_tests.
- Algorithm: first pass realizes content-bearing motifs as today; then iterate the content-less `derivedFrom` figure-motifs, resolving any whose parent is already in `realizedMotifs`, looping until fixpoint; leftovers throw naming the motif (missing parent or cycle). Seed per motif: `generationSeed ? generationSeed : rng.rng()`. Store to `realizedMotifs[name]` (and stamp the Motif's content so a saved template keeps what sounded).
- Tests: chain (b derivedFrom a, c derivedFrom b) resolves; missing parent throws with name; content-bearing derived motif NOT re-derived; vary_steps derivation deterministic per generationSeed; rep3+complexify(4) support check (some seed yields 4 units).
- Commit.

### Task 3: anchor_selector.h + anchorMode integration
- Files: create engine/include/mforce/music/anchor_selector.h; templates.h (`std::string anchorMode;` on PassageTemplate + doc comment); templates_json.h (roundtrip, emit only when non-empty); composer.h (`compose_passage`: when `anchorMode == "harmonic"`, run selector per phrase on `localTmpl` before `compose_phrase` — after the existing startingPitch/parallel handling, replacing it for this mode); engine_tests.
- Selector API: `void select_anchors(PhraseTemplate& localTmpl, const std::vector<const MelodicFigure*>& figures, const HarmonyTimeline& timeline, const Scale& scale, float phraseStartBeat, float beatsPerBar, float defaultPulse, bool isPassageFinal, std::optional<Pitch> pinnedStart, const Pitch& registerAnchor, Randomizer& rng)`.
  - Figures resolved by the caller from realizedMotifs (Reference) / lockedFigure (Locked) / literalNotes — throw for Generate sources under harmonic mode (out of scope).
  - Enumerate A₀ ∈ chord tones of chord at phraseStartBeat within ±4 scale steps of registerAnchor (respect pinnedStart when set: single candidate); leadSteps ∈ [−4,+4] per subsequent figure. Realize degree/beat track per chain; hard R1 (A₀ chord tone — true by construction), R2 (last note chord tone at its beat), R3 (isPassageFinal ⇒ last note degree ≡ scale degree 1); score per spec §3; roulette ∝ exp(score); write startingPitch + dense connectors ([null,...] = FigureConnector defaults for [0]).
  - Beat tracking from figure durations; chord lookup via `timeline` segment/progression at beat (mirror realize's lookup).
- compose_passage passes: phraseStartBeat accumulated from prior phrases' total durations; pinnedStart = previous phrase's chosen startingPitch when `parallel`; registerAnchor = authored phrase/passage startingPitch; isPassageFinal for the last phrase.
- Tests (toy timeline C | G7): R1 (start is chord tone across 50 seeds); R2/R3 (final note chord tone / tonic across seeds); boost flip (two chains differing only in whether a long figure-final note is a chord tone — the boosted chain wins at low temperature across seeds); parallel pinning (phrase 2 A₀ == phrase 1 A₀); empty-legal throws (timeline where no candidate satisfies R3).
- Null gate template corpus before/after (all opt-in ⇒ byte-identical). Commit.
